Game Jam 2 was a two-week game jam where each participant was asked to make a cute cozy game with pets as the theme. 
I decided to make a game where the player is a cat going on a hike. 
I imported royalty free music and a good amount of free premade assets. 
Most of my work went into creating a camera that was similar to the one that Dead by Daylight has and interactive UI pop-ups for the NPCs.
